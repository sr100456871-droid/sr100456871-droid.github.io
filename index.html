流程

我怎么用 Codex 做内容任务

我在用的不是“问一个答案就结束”的方式，而是把 Codex 放进完整任务流里，让它参与拆解、生成、修改、上线和复盘。

1. 先把模糊要求拆成清晰任务

把岗位截图、修改意见和展示目标整理成信息点，明确首页主信息、案例结构和沟通重点，再决定页面先改什么。

2. 让内容和页面一起生成

不是只让 AI 写几段话，而是直接让 Codex 帮我改网页、改版式、改标题、改按钮、改下载材料，让内容真正变成可见页面。

3. 把结果上线，再继续迭代

做完后立刻部署到 GitHub Pages，检查链接、移动端、下载链路和分享信息，再根据招聘方需求继续快速改版。
